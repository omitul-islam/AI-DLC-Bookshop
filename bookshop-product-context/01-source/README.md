# Source Documents

## Purpose
This folder contains original source documents that informed the product development.

## Contents

### 01-requirements/
Original requirements documents collected from stakeholders

### 02-user-stories/
Initial user stories gathered during inception phase

### 03-design-artifacts/

These documents are preserved for reference and traceability. They should not be modified after initial archival.

All derived documentation is organized in other folders (02-domain, 04-architecture, etc.).
